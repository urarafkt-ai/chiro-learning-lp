# 画像の差し替えについて

このフォルダに、以下の**同じファイル名**で写真を追加してください。
ファイル名さえ合っていれば、HTML側は何も変更する必要はありません。

| ファイル名 | 使用箇所 | 内容の目安 |
|---|---|---|
| `hero-ando-lecture.jpg` | ファーストビュー(1番上) | 骨格模型を持って、少人数に身体について説明・指導している写真(縦位置) |
| `ando-profile.jpg` | 安藤真奈美のストーリー | 安藤本人の自然な写真 |
| `classroom-lecture.jpg` | 「何を学ぶのか」セクション | 男女が参加している講義・勉強会の写真 |
| `ando-practice.jpg` | 学びのステップセクション | 安藤が実際に技術指導している写真 |
| `group-practice.jpg` | 学びのステップセクション(後半) | 多人数で技術練習している写真 |
| `posture-tablet.jpg` | 無料姿勢講座＋説明会セクション | タブレットを見せながら姿勢を説明している写真(正方形) |

## アップロード方法(GitHubのWeb画面から)

1. GitHubでこの `images` フォルダを開く
2. 差し替えたい写真と同じファイル名のファイルを開き、鉛筆アイコン(Edit)→「Upload」または「Replace this file」で上書き
   (新規追加の場合は「Add file」→「Upload files」)
3. 写真をドラッグ＆ドロップ(ファイル名を上の表と同じにする)
4. 画面下の「Commit changes」をクリック

数十秒〜数分で、公開中のページにも自動的に反映されます。
